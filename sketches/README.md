# Sketches Lentera

Empat arah visual, semuanya dirender dengan peta Indonesia asli dan data BNPB 2024.

| Folder | Arah | Status |
|---|---|---|
| 001-terang-editorial | Dua kolom, editorial, ruang lega | Dieksplorasi |
| 002-gelap-operasional | Tema gelap, padat, seperti alat kerja | Dieksplorasi |
| 003-peta-dulu | Peta penuh layar, tema terang sejuk | Dieksplorasi |
| 004-gabungan-peta-editorial | Peta penuh layar dengan gaya editorial | Dipilih untuk tampilan pertama |
| 011-gulir-daftar-wilayah | Tiga variasi gulir untuk daftar wilayah dan panel detail | Dieksplorasi |

## Keputusan

19 Oktober 2026: arah 004 dipilih untuk semua layar, bukan hanya layar pertama. Tampilan pertama memakai peta bersih, panel detail baru muncul setelah pengguna memilih wilayah.

## Cara membuka

Buka file index.html tiap folder langsung di browser. Tidak perlu server.

Contoh:
C:\Users\Lenovo\Documents\Lomba\MIA 2026 miamiudua\Lentera\sketches\004-gabungan-peta-editorial\index.html

Screenshot hasil render ada di folder _pratinjau.

## Berkas bersama

Folder themes berisi map-paths.js, yaitu jalur SVG 517 wilayah kabupaten, garis besar negara tetangga, dan nilai kejadian 2024 dari BNPB. Dibuat dari geoBoundaries ADM2 dan data BNPB.

## Sifat berkas ini

Sketch bersifat sekali pakai. Kalau satu arah dipilih, keputusan visualnya dipindahkan ke 02-ux-design/04-design-system.md, tidak dipelihara sebagai aset di sini.
